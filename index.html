Getting started

You need DeepDarkShare on both devices and an internet connection (Wi-Fi or mobile data). The two devices do not need to be on the same network.

↓To receive files

  1. Open DeepDarkShare and tap Receive.
  2. Wait until the QR code appears and shows Ready (usually 10–60 seconds while Tor connects).
  3. Let the sender scan the QR code, or tap Can't scan? Show code and read it out, or use Share link.
  4. When "… wants to send you N files" appears, check the name and files, then tap Accept.
  5. Keep the screen open until it says Received. Open the files from there, from History, or in the Files app.

↑To send files

  1. Tap Send and choose items from Photos, Videos, Files or files you received earlier.
  2. Tap SEND.
  3. Scan the receiver's QR code, or type their code, or Paste the link they sent you.
  4. Check that the safety code (four emoji) matches the one on the receiver's screen.
  5. Wait for the receiver to accept. The files then transfer and the screen shows Sent.

Typing a code and the safety code

If the camera isn't available, the receiver can show an 84-character code in groups of four. Type it on the sender's Send screen under OR TYPE THE CODE.

  • Capital or small letters both work, and spaces, dashes and line breaks are ignored.
  • The code only uses letters and the numbers 2–7. If you type 0 or 1, they're read as the letters o and l.
  • A built-in check spots typos straight away: you'll see The code has a typo instead of waiting.
  • After connecting, compare the safety code on both phones. Matching emoji mean you reached the phone you intended. If they differ, stop and ask for a new code.
  • A code works only while the receiver keeps their Receive screen open. Every new Receive makes a new code.

Troubleshooting

The messages below are the ones you may see in the app.

It stays on "Connecting to Tor" for a long time
  • Check that the device is online (try opening a website in Safari).
  • On public Wi-Fi with a sign-in page, sign in through Safari first, then return to the app.
  • Try switching between Wi-Fi and mobile data. Some networks block Tor.
  • Make sure Settings › General › Date & Time › Set Automatically is on. Tor needs a correct clock, and the app will tell you if it isn't.
  • The first connection after installing can take a minute or two; later ones are faster.
"Couldn't reach the receiver" or the sender keeps retrying

A brand-new receive code can take up to a minute to become reachable on Tor (the receiver's screen shows Going live… until then), so the sender retries automatically for up to four minutes. If it still fails, make sure the receiver's Receive screen is still open and their device is unlocked, then try again. If the receiver left the screen, ask for a new code.

"The code has a typo" / "The code is N characters short"

Compare your typing with the receiver's screen group by group. The code is exactly 84 characters. If you received the code as a link in a message, use Paste instead of typing.

"The receiver didn't accept this code"

The code you used doesn't match the receiver's current code: it may be mistyped or from an earlier Receive session. Ask the receiver for the code currently on their screen.

"The receiver declined the files" / "The receiver didn't answer"

The receiver tapped Decline, or didn't respond within 90 seconds. Ask them to watch for the prompt and tap Accept, then send again.

"The receiver is busy with another transfer"

The receiver accepts one transfer at a time. Wait until their current transfer finishes, then send again.

The transfer stopped part way

A transfer needs both apps to stay open. iOS pauses apps that are in the background, and the connection is lost if either device locks or switches apps for too long. Files that finished before the interruption are kept; send the rest again. Keep both screens on during large transfers.

Where are my received files?
  • In the app: the HISTORY tab. Tap a thumbnail to open it, or use the … menu to share or delete.
  • In the Files app: On My iPhone (or iPad) › DeepDarkShare › Received, in a folder named by date and time.
  • To save a photo or video to your library, open it, tap Share, then Save.
The camera shows "Camera access is off"

Open Settings › DeepDarkShare and turn on Camera, or simply type or paste the receiver's code instead. The camera is used only to scan QR codes.

Transfers feel slow

Tor routes your data through six encrypted relays to protect your privacy, so it's slower than a direct connection. Typical speeds are a few hundred kilobytes per second. In Settings › Tor network, Use new circuits picks fresh relays, which sometimes helps.

How do I delete my data?

Delete individual transfers from the HISTORY tab, or use Settings › Clear history (you can choose to delete the received files too). Deleting the app removes everything it stored. We hold no data about you to delete on our side.

Staying safe

  • Share receive codes only with people you trust, and only while you expect files.
  • Only accept files you're expecting. Be careful opening files from strangers.
  • When a code reaches you by message, compare the safety code by voice or in person before sending anything sensitive.
  • Your display name is visible to the other person. Keep the random one if you prefer to stay anonymous.
